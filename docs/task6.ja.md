# task6: 画像プレビュー（サムネイル・サイズ調整・クリック拡大）

> **注**: この機能はtask4完了後（task5の前）にアドホックに実装したもの。
> task1と同様に、実装済みの挙動の記録としてこのファイルを残す。

## 目的

ファイル名だけでなく画像を見て並び順を決めたり、画質（ボケていないか等）を
確認できるようにする。

## 挙動

### サムネイル

- ①のファイルリストでは各ファイル名の左に、③のプレビュー表では左端の列に
  サムネイルを表示する
- 画像ファイル（MIMEタイプ `image/*`）はオブジェクトURL
  （`URL.createObjectURL`）で表示し、`object-fit: cover` で正方形に
  トリミングする。オブジェクトURLはファイルをリストから削除した時に
  revokeする
- 画像以外のファイルは 📄 のプレースホルダーを表示する

### サイズ調整

- 「画像サイズ − ＋」コントロールを①の並べ替えヒント
  （「ドラッグ&ドロップで並べ替えできます…」）の直下に表示する
  （ファイルがあるときのみ）
- 範囲は24〜164px・20px刻み・初期値44px。上限・下限で − / ＋ ボタンを
  disabledにする
- サイズはCSS変数 `--thumb-size` で適用し、①と③が連動して変わる

### クリック拡大（ライトボックス）

- ①③どちらでも、画像サムネイルをクリックすると画面全体のオーバーレイで
  プレビューを表示する
- 画像は**実寸**で表示し、画面内に収まるよう上限を設ける
  （`max-width: calc(100vw - 3rem)`、`max-height: calc(100vh - 6rem)`、
  縦横比は維持）。画面より小さい画像は拡大しない
- 画像の下にファイル名を表示する。閉じる方法は「背景クリック」「✕ボタン」
  「Escキー」
- ドラッグでの並べ替えと干渉しない（ドラッグはポインタ8px以上の移動で
  発動）。プレースホルダー（画像以外）はクリック対象外

## 制約

- 追加ライブラリなし・プレーンCSS・React portalで描画
- すべてブラウザ内処理（オブジェクトURLはローカルのBlob参照）で、
  CLAUDE.md のプライバシー方針と整合する

## 完了条件

- `npm run build` / `npm run lint` / `npm run test` がすべて通る
- ブラウザで、サムネイル表示・①③連動のサイズ変更・ライトボックスの
  開閉が仕様どおり動くことを確認する

## やらないこと

- 画像の編集・回転、EXIF対応、動画のサムネイル
- サムネイルサイズの永続化
